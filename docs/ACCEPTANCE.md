# CSL pilot acceptance checklist

- [ ] CSL branding, mobile home page, company and product pages
- [ ] Login and role isolation; synthetic customer and staff accounts
- [ ] Design editor saves/uploads/loads a real revision
- [ ] Submit quote/order, staff sees it; tracking reference assigned
- [ ] Customer comments on proof and approves an exact revision
- [ ] Staff updates production stages; customer sees dated timeline
- [ ] Multiple shipments/tracking references accommodated in model
- [ ] Reorder creates new order with linked original design
- [ ] Kimi request actually hits Moonshot API with configured key and fails gracefully
- [ ] No key sent to browser or stored in Git
- [ ] All unconnected features visibly marked Pending integration
- [ ] ERPNext is tested before claiming synchronization
- [ ] NAS/Drive access respects file ACLs and doesn't expose originals publicly
- [ ] HTTPS, security tests, backups and rollback verified before client access
